# Seminar Slides

This directory will contain slide materials for the **nine-hour seminar**, organised as three three-hour days with ten modules per day. Each 17-minute module has a six-minute rigorous presentation, a five-minute instructor demonstration, and a six-minute BYOD activity using separate public data or a participant upload.

| Day | Modules | Slide-material emphasis |
|---|---:|---|
| Day 1 | 10 | Data, measurement, distributions, random variation, confidence intervals, bootstrap, simulation, and assumptions |
| Day 2 | 10 | Hypotheses, effect sizes, group comparisons, ANOVA, nonparametrics, categorical inference, stratification, and design sensitivity |
| Day 3 | 10 | Linear and logistic regression, prediction, diagnostics, validation, reproducibility, and transparent reporting |

Every module's slides should state the formal definitions, notation, assumptions, and results without proofs; clearly identify the instructor demonstration dataset; list the three different public BYOD datasets; and point participants to the option to upload their own CSV in the Streamlit app.

The initial repository does not yet contain rendered slide decks. The authoritative module sequence and data assignments are in [`data/module_manifest.json`](../data/module_manifest.json) and [`docs/seminar_design.md`](../docs/seminar_design.md).
